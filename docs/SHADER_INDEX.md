## Local file formats

- GLSL uses Shadertoy's `void mainImage(out vec4 color, in vec2 fragCoord)`. Browser Auto selects WebGL2 for GLSL. Desktop and browser WebGPU use the prepared fragment.
- WGSL accepts `fn mainImage(fragCoord: vec2<f32>) -> vec4<f32>` with the lab prelude, or a complete fragment module with compatible bindings. `tests/fixtures/rainbow.wgsl` exercises a single fragment entry point using the injected uniform block.
- HLSL accepts a pixel shader with entry point `main` and an `SV_Target` return semantic. Slang compiles it on the desktop or in the browser worker. For a working uniform and texture declaration, use **View code → HLSL → Copy shader**. WebGPU is required in the browser for WGSL and HLSL.
- Each multipass file contains ordered `//! PASS: Buffer A` sections followed by `//! PASS: Image`. A channel declaration such as `//! iChannel0: Buffer A` wires an input. `self` reads the previous frame and `keyboard` provides a 256 × 3 key-state texture. Empty channels bind a black 1 × 1 texture.
- The shared binding group uses the 144-byte uniform block at slot 0, four textures at slots 1–4 and a linear sampler at slot 5. Source generated by the inspector includes register assignments. External engine-specific includes, material graphs, compute shaders and arbitrary user texture assets are outside this fragment interface.

## Regression assets

`tests/fixtures/centering.wgsl` draws a centered disk, ring and cross through three buffers and Image. `tests/reference/` stores original WebGL2 frames at 1280 × 720. The GPU checks use frame 7 after an eight-frame run, a 60 Hz shader clock and neutral input. Star patterns in Cyberspace vary across shader compilers. The comparison measures normalized mean absolute RGB error after a 160 × 90 box filter, with limits of 0.015 for Kerr–Newman and 0.055 for Cyberspace, and checks geometry independently to within one pixel. Archived scratch shaders live in `docs/shader-archive/`.
